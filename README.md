# Slot Machine

A small arcade slot-machine web game. Each spin picks one item from each of three reels.

## Editing the reels

Everything that can come up on a reel lives in [`src/data/reels.json`](src/data/reels.json).
Edit it on GitHub or locally; the site redeploys when `main` changes.

## Development

```bash
npm install
npm run dev
```

`npm run build` outputs a static site to `dist/`.
